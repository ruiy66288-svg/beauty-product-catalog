# 美妆产品目录

无需安装依赖的静态网站。直接打开 `dist/index.html` 可使用；也可将 `dist` 内全部文件上传至静态网站托管或 Nginx 网站目录。所有资源均为本地相对路径。

GitHub Pages 通过 `.github/workflows/pages.yml` 自动发布 `dist`。推送到 `main` 时先核验目录数据，再部署网站；其他源码与审计文件不进入网页发布包。

网站入口要求输入访问密码，刷新后需重新输入。`dist/access.js` 管理入口，验证通过后加载目录。此功能仅为静态页面访问提示，不保护公开仓库、数据文件和图片，不等于服务端鉴权。

## 内容整理

- 来源：用户提供的原始产品表，38 个工作表。
- 678 条产品记录，670 条含图片，8 条暂无图片，25 条原规格字段缺失。
- 按表头定位字段，展开合并单元格，保留原有品牌分组及规格色号。
- 不导入任何价格列；商品名称中的报价附注已移除。原始工作簿不在网站目录中。
- 欧舒丹第 36 行与第 25 行完全重复，合并展示；第 23、41 行名称无效，未列入目录；第 48 行为搭配说明，未作为商品发布。
- 名称、规格相同但图片不同的记录保留，避免误合并不同版本。
- 不收录贸易属性、资质资料、配送说明；页面与发布数据均移除这些字段。
- `audit.json` 保存分组计数与异常记录，不属于网站发布目录。

## 使用与维护

搜索名称、品牌、色号或规格；按品牌和原表包装标注筛选；打开详情可复制产品信息；导出当前筛选结果为不含价格的 CSV。

产品数据位于 `dist/catalog.js`，图片位于 `dist/assets`，界面为 `dist/index.html`、`style.css`、`app.js`。修改后运行 `node verify.mjs`。

## 验证

执行数据字段白名单、记录数、唯一编号、图像文件存在、价格文本残留扫描；浏览器验证搜索、品牌筛选、详情、分页、空结果和重置。图片已用全量缩略图检查，部分密集文字图另行放大检查。移动端使用响应式 CSS，未以实体手机验收。
